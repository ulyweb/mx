Launcher Script

One-command run

Everything automated: install, checksum, IPSW, DFU wait, GUI launch, log and HTML receipt.

1

Get the launcher onto the MX Linux PC

Download it here, or copy it from the Launcher Script tab.

cd ~/Downloads && chmod +x mac_dfu_restore.sh && ./mac_dfu_restore.sh
2

Follow the on-screen prompts

The script walks you through: firmware choice → DFU instructions → waits until the Mac shows as DFU → opens RestoreKit → tells you exactly what to click.

3

Audit trail

Each run writes to ~/Mac_DFU_Restore/<timestamp>_run/: restore.log (plain text) and receipt.html (telemetry receipt, auto-opened).

Heads-up: the restore erases the Mac completely. If Activation Lock or MDM enrollment appears afterward, you need the Apple ID / Jamf release - the restore cannot bypass it.

Run checklist

1 · Prep (PC side)

What you need before touching the Mac.

Hardware

  • USB-C data cable (a USB-A to USB-C cable is often more reliable)
  • Mac on MagSafe power (charge via MagSafe, not the DFU port)
  • No hubs or docks between PC and Mac

PC

  • MX Linux x86_64 with sudo
  • ~25 GB free disk, internet to Apple's CDN
  • Chrome/Chromium only needed for Live Detect (optional)
✓

What the launcher installs

RestoreKit_0.5.10_amd64.deb from the official GitHub release, verified against its published SHA-256, plus the USB udev rule (so no sudo needed for device access).

sha256  ca57a35980adb3b586dcb316833be0fe6336cdcf14b867e20da10900d6b074b6
The earlier idevicerestore source build failed on a missing libtatsu dependency, and the USB installer path hit "installer is damaged". Both are retired - RestoreKit's prebuilt package avoids them.

2 · Firmware

Pick the macOS version. Follow your corporate-approved baseline, not simply the newest.

The launcher resumes partial downloads and also reuses a copy already in ~/Downloads/macos_ipsw. Size is checked against Apple's Content-Length.

3 · DFU mode

The screen stays black in DFU - confirm with Live Detect or lsusb.

1

Mac fully OFF + MagSafe in

Shut down completely. Plug MagSafe power in.

2

Cable to the correct port

USB-C data cable from the Mac's LEFT-side port next to MagSafe to the PC. (An earlier note said "closest to the screen" - that was wrong for the 14"/16" MBP.)

3

Key sequence

Hold Power + Right Shift + Left Control + Left Option for ~10 s, release the three keys, keep holding Power ~5 more seconds.

4

Verify

lsusb | grep -i 05ac
# want:  ID 05ac:1227 Apple, Inc. Mobile Device (DFU Mode)
# seeing 05ac:1902 "MacBook Pro" = NOT DFU -> shut down, redo the keys

Live Detect (WebUSB)

Optional. Chromium-based browsers only. Confirms the PC sees the Mac and whether it is in DFU.

Status: NO DEVICE
waiting...
If the browser lists no device or errors, use lsusb | grep -i 05ac in a terminal instead - the launcher does this for you anyway. WebUSB needs a Chromium browser and a permission click; it only identifies the device and never writes to it.
