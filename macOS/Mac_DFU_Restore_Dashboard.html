🛡System Preflight — verified when this page opens
Scan: NO SCAN DATA
A web page cannot see installed packages, your Downloads folder or lsusb on its own. The console script does that scan, fixes what is missing, and re-opens this dashboard with the results embedded and digest-verified.
💡 HOW THE AUTO-CHECK WORKS

1. Run the console script once: it scans RestoreKit (package + .deb checksum), the udev rule, required tools, every *Restore.ipsw in ~/Downloads and ~/Mac_DFU_Restore/ipsw (size-checked against Apple), check_dfu.sh, the restore launcher, network, disk space and USB.

2. It fixes what is missing (checksum-verified), writes preflight.json + SHA-256 + a plain-text log + receipt, and opens ~/Mac_DFU_Restore/Mac_DFU_Restore_Console.html — this page with the results embedded.

3. On open, this page re-hashes the embedded scan, shows the verdict, auto-ticks what was proven, and hash-chains it all into the audit ledger. A scan older than 30 minutes is flagged STALE.

    ✅Run Checklist — drives the phase rings
    💡 WHAT THIS PANEL IS FOR

    Progress here is real state, not decoration: the three phase rings in Live Telemetry, the KPI strip and the audit ledger are all computed from it. Every tick is hash-chained into the ledger.

    💾Firmware — pick the macOS version

    Follow your corporate-approved baseline, not simply the newest. The launcher offers the same four choices.

    💡 NOTES

    The launcher resumes partial downloads, reuses a copy already in ~/Downloads/macos_ipsw, and verifies size against Apple's Content-Length. In RestoreKit use Local IPSW → browse for a pinned version; leave latest signed otherwise.

    ⚡DFU Mode — hardware steps
    1. Mac fully OFF and MagSafe power plugged in (charge via MagSafe, not the DFU port).
    2. Cable: USB-C data cable from the Mac's LEFT-side port next to MagSafe → the PC. No hubs or docks. A USB-A → USB-C cable is often more reliable.
    3. Keys: hold Power + Right Shift + Left Control + Left Option ~10 s, release the three keys, keep holding Power ~5 s more. The screen stays black — that is normal.
    4. Verify: lsusb | grep -i 05ac must show 05ac:1227 … (DFU Mode).
    ⚠ CORRECTION LOGGED

    An early note said "port closest to the screen". That was wrong for the 14"/16" MacBook Pro — the DFU port is the one next to MagSafe. 05ac:1902 MacBook Pro means the Mac is up but not in DFU: shut down and redo the keys.

    ◉Live Detect (WebUSB)

    💡 HOW IT WORKS

    Chromium-based browsers only. WebUSB needs a permission click and only identifies the device (vendor 0x05ac) — it never writes to it. If the browser lists nothing, use lsusb | grep -i 05ac; the launcher does the same check for you.
